# 音记的闯关界面

2026-10-04 根据使用者反馈，将首页从阶段目录、课程详情和统计卡并排的结构，改为以学习路线为主体的闯关游戏。

## 交互与布局

- 每章 6 关，用弯曲路线连接。已通过的关卡显示金色星章，可重练；当前可学的关卡显示紫色玻璃节点；后续关卡显示锁。阶段考核使用奖杯。
- 新学习者从第一关开始，客观题达到 80% 才解锁下一关；未通过时返回同一关。通过章节末关后进入下一章。既有通关记录和正在恢复的课程继续可用。
- 点击节点选择当前任务；查看课名、时长、例词和示范，然后开始。长讲解与长题目仍在学习区内滚动，核心操作保持可达。
- 电脑与 iPad 使用横屏布局：窄功能导航、中央关卡路线、右侧当前关预览。较窄平板缩小导航宽度，保留相同的布局关系。
- 600 CSS 像素及以下隐藏常驻菜单。iPhone 顶部菜单按钮打开模态菜单，选择目的地后关闭；Esc 或关闭后焦点回到菜单按钮。语言按钮一直在右上角。
- 手机当前关任务栏固定在底部安全区上方，主路线可以滚动。学习答题时使用进度条、带按压反馈的选项及底部检查/继续按钮。
- 通关结果配合原创小音精灵与星星反馈。学习日、星章和单词数量均由真实记录计算，没有虚构奖励或付费通关门槛。减少动画设置关闭非必要动画。
- 恢复课程时，客户端先定位其真实章节和关卡；完成后返回该课程的下一关，避免跳回第一章。

## 实现

`app/GamePath.tsx` 负责关卡图、当前任务及章节选择；`app/game.css` 负责游戏布局，`app/liquid.css` 负责紫色玻璃主题，`app/LiquidIndicator.tsx` 负责共享选中透镜；`app/LearningApp.tsx` 保留既有课程、答题、复习、账号保存功能并管理解锁与手机菜单。`public/sound-buddy.svg` 是原创矢量声音精灵，无脚本和外链。

## 紫色玻璃主题与原创流线标志

按使用者提供的参考图调整为白色内容面、下方紫粉环境光、轻量字重及圆润胶囊控件。玻璃按钮与卡片使用半透明底、边缘高光、内外阴影和适度背景模糊；正文保持稳定、清晰的内容层。主色为紫罗兰，正确/错误反馈继续保留语义颜色。

`public/yinji-mark.svg` 是原创、无文字的音形流线标志：用填充路径形成粗细不均的连续曲线、不对称回环与两个倾斜端部，紫色明暗表现折叠关系。没有外框，80×80 画布的墨迹与四周至少保持 12.8 单位留白。页头、章节入口和 favicon 共用同一符号。

导航、音标分类、章节选择、手机菜单和答题选项使用同一个持续存在的玻璃背景随选择移动，关卡使用移动玻璃环。移动中轻微拉伸、扩散高光，再收拢落位；尺寸变化后重新测量，不移动文字。菜单选择立即切换内容并在 220ms 后关闭，保留焦点恢复；快速再次选择和卸载会取消旧计时器。系统减少动态效果时即时切换，高对比度与不支持背景模糊时使用更实的底色。
